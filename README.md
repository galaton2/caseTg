# GiftCases — фронтенд мини-аппа для Telegram

Готовый фронтенд игры "открытие кейсов" в стиле CS:GO для Telegram Mini App.
Сейчас всё работает **полностью на клиенте** (баланс и инвентарь лежат в `localStorage`
браузера) — это нормально для теста, но перед реальным запуском часть логики
нужно перенести на сервер (см. раздел ниже).

## Что внутри

- `index.html` — разметка
- `style.css` — стили, тёмная тема, анимации редкости
- `script.js` — вся логика игры

## Кейсы (текущие тестовые шансы)

**Бесплатный кейс** (шанс 99 к 1, кулдаун 8 часов):
| Приз | Шанс |
|---|---|
| 🪙 Счастливая монета | 99% |
| 🧸 Плюшевый мишка | 0.6% |
| 💍 Кольцо-сюрприз | 0.3% |
| 🏆 Золотой кубок | 0.1% |

**Премиум кейс** (15 ⭐, гарантированный приз, без пустых открытий):
| Приз | Шанс |
|---|---|
| 🌹 Роза | 55% |
| 🎂 Праздничный торт | 28% |
| 🎁 Подарочная коробка | 12% |
| 🚀 Ракета | 4% |
| 👑 Корона | 1% |

Всё это задаётся в объекте `CASES` в начале `script.js` — можно менять названия,
иконки (эмодзи), веса шансов и стоимость как угодно.

## Как посмотреть локально

Открыть просто как файл браузер не даст (Telegram SDK и некоторые API требуют http).
Проще всего:

```bash
cd tg-case-game
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

Внутри обычного браузера (не в Telegram) игра тоже работает — весь код,
завязанный на `Telegram.WebApp`, обёрнут в проверки `if (tg) {...}` и просто
не выполняется.

## Как подключить как настоящий Mini App

1. Залить эти 3 файла на любой https-хостинг (GitHub Pages, Vercel, Netlify — подойдёт любой).
2. В **@BotFather** → выбрать бота → *Bot Settings → Menu Button* (или `/newapp`) → указать
   ссылку на `index.html`.
3. Открыть бота в Telegram — кнопка меню откроет игру.

## Важно: что обязательно перенести на сервер перед реальным запуском

Сейчас результат кейса генерирует сам браузер — это ок для демо, но означает,
что через консоль браузера результат можно подделать, а баланс живёт только
на устройстве пользователя. В коде такие места помечены комментарием
`// [SERVER TODO]`, вот они:

1. **Баланс звёзд и инвентарь** — сейчас в `localStorage`. Должны приходить
   с сервера при открытии аппа (по `initData` пользователя) и обновляться
   там же после каждого действия.
2. **Покупка кейса за 15 ⭐** — сейчас баланс просто списывается в браузере
   (`chargeStars`). В проде нужно использовать Telegram Stars-инвойс:
   бэкенд создаёт ссылку через Bot API `createInvoiceLink` с `currency: "XTR"`,
   а фронт открывает её через `tg.openInvoice(link, callback)`; кейс должен
   открываться только после успешной оплаты.
3. **Кто выпал из кейса** (`pickWeighted` в функции `spin()`) — сейчас выбор
   делает браузер. На сервере должна быть аналогичная функция с "секретными"
   весами; сервер присылает готовый результат, а клиент только красиво
   прокручивает рулетку до этого предмета (функция `buildReel` уже принимает
   `forcedWinner` — её как раз для этого и делал).
4. **Вывод подарка** (`withdrawActiveItem` → `sendToBot`) — сейчас просто
   вызывает `tg.sendData(...)`, что реально отправляет сообщение боту, но бот
   должен сам проверить `initData`, списать предмет из серверного инвентаря
   и отправить пользователю настоящий Telegram-подарок.
5. **Продажа предмета за звёзды** — по-хорошему тоже должна подтверждаться
   сервером, чтобы нельзя было накрутить баланс через консоль.

## Что уже реализовано на фронтенде

- Анимированная рулетка (вращение с плавным замедлением, как в CS:GO/кейсах),
  с "тиканьем" звука по мере прохождения предметов и подсветкой выигранного слота
- Два кейса с настраиваемыми шансами и ценами
- Гарантированный 100%-й кейс за звёзды и бесплатный кейс с кулдауном 8ч и таймером обратного отсчёта
- Звуки на все действия — сгенерированы через Web Audio API (без внешних файлов),
  можно отключить кнопкой
- Конфертти-эффект при редких/эпических/легендарных выигрышах
- Инвентарь с продажей за звёзды или "выводом" через `tg.sendData`
- Живая лента "выигрышей других игроков" для атмосферы (демо-данные)
- Модалка результата, тосты, кнопка "быстрое открытие" (без анимации)
- Адаптивная вёрстка (мобильные экраны, safe-area для iPhone, уменьшенные
  размеры на узких экранах), поддержка `prefers-reduced-motion`
- Интеграция с Telegram WebApp: `ready()/expand()`, цвет хедера, хаптик-фидбек
  на действия, безопасная работа и вне Telegram (просто как обычный сайт)
